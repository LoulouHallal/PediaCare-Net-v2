# Data access and derived artifacts

PediaCare-Net v2 keeps source code and large patient-level data artifacts separate. This document records exactly what a researcher needs to reproduce the thesis pipeline.

## Official source data

MetaboNet data portal: https://metabo-net.org/data

The final preprocessing pipeline uses `metabonet_public.parquet` as the raw longitudinal source.

## Pediatric cohort

The thesis cohort contains 244 subjects. Historical reconstruction confirmed that the pediatric selection was based on:

```text
age_first < 18 years
```

The exact historical cohort used in the experiments is preserved in `metabonet_windows_pediatric.npz`. In the released code this file supplies the 244 subject identifiers, while `src/build_windows.py` re-reads those subjects from the raw MetaboNet parquet and rebuilds the final causal representation.

## Thesis-derived package

Download: `https://drive.google.com/drive/folders/16LMOLM-NG2w6ktN8AZbZaO2q4pkPjLsL`

Expected contents:

```text
metabonet_windows_pediatric.npz
windows_stride6.npz
windows_stride6_meta.json
windows_eval.npz
windows_eval_meta.json
raw_treatment_stride6.npz
patient_context_stride6.npz
nadir_targets_stride6.npz
features_stride6.npy
cgm_timeline_metabonet.parquet
cgm_timeline_metabonet_coverage.json
```

The package may be public or controlled-access depending on the redistribution terms that apply to the source data. The Git repository itself should continue to contain code and aggregate thesis results only.

## Which files are needed for which task?

- To **rebuild preprocessing**, use `metabonet_public.parquet` + `metabonet_windows_pediatric.npz`.
- To **rerun the main deep-learning experiments without rebuilding preprocessing**, use `windows_stride6.npz` and `windows_eval.npz` plus their metadata files.
- To **rerun classical ML**, `features_stride6.npy` can be regenerated by the classical pipeline or supplied from the derived package.
- To **rerun treatment diagnostics / selected explanation workflows**, use `raw_treatment_stride6.npz`.
- `patient_context_stride6.npz` and `nadir_targets_stride6.npz` belong to exploratory experiments and are not required for the final seven-channel TSL-GRU input.
- The CGM timeline parquet and coverage JSON support event-level and monitoring-duration analyses.
